## What is Docker?
Docker is a platform for packaging, distributing and running applications inside lightweight portable units called containers.

Docker Containers include:
- Code
- Python Ver
- Libraries
- Dependencies 
- Env Variables 
- OS-level settings
## Docker Container
A container is a lightweight isolated box/env, that runs your app with
- its own file system
- its own dependencies 
- it own processes
- but share the host OS kernel
