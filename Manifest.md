In Kubernetes, a **manifest** is a configuration file (usually written in YAML) that describes the desired state of a **Kubernetes object**.

Think of it as an instruction sheet that tells Kubernetes:

- what to create
- how it should run
- how many replicas to maintain
- what image to use
- networking, storage, environment variables, etc.

Common Kubernetes objects defined in manifests include:

- Pods
- Deployments
- Services
- ConfigMaps
- Ingresses
- PersistentVolumes
